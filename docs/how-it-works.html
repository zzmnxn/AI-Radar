실행·운영

Actions는 기본 파일 저장 또는 PostgreSQL 수집 저장을 사용한다. Pages는 검증된 JSON을 읽는다. 실패해도 이전 브리핑은 지킨다.

하루 실행 흐름

.github/workflows/daily.yml · ci.yml · .github/scripts/commit-data.sh

pipeline contents: write

  1. radar run 실패해도 계속
  2. radar validate-data
  3. 커밋·푸시 검증 통과 + data/ 변경 시
  4. 로그 artifact 30일

deploy pages: write

  1. 그 HEAD checkout
  2. 다시 검증
  3. 웹 빌드
  4. Pages 배포

검증 통과면 커밋이 없어도 배포 → 전날 배포 실패를 자동 복구

  1. data · commit · deploy 결과를 따로 표로
